# 🎹 피아노 악보 변환기

음악 파일(MP3·WAV·M4A 등)이나 마이크 녹음을 올리면 **음을 분석해서 피아노 악보를 그리고, 피아노 연주(MIDI·WAV)와 악보(MusicXML)를 만들어 주는** 웹사이트입니다.

- **서버가 필요 없습니다.** 모든 분석은 사용자의 브라우저 안에서 이루어지며 파일은 어디로도 전송되지 않습니다.
- 빌드 과정이 없는 순수 정적 사이트입니다(HTML + ES 모듈). 정적 호스팅(GitHub Pages, Netlify 등)에 그대로 올리면 됩니다.

## 주요 기능

| | |
| --- | --- |
| 입력 | 오디오 파일 끌어놓기 / 선택, 마이크 녹음, 내장 예시 곡 |
| 분석 | **AI 정밀 분석**(Spotify Basic Pitch, GPU 가속) 또는 **내장 빠른 분석**(신호처리 방식, 모델 없이 동작) — AI 엔진이 실패하면 자동으로 내장 엔진으로 전환 |
| 자동 추정 | 템포·박자 위치(비트 트래킹), 마디 시작, 조성(조표), 오른손/왼손 분리 |
| 악보 | 대악보(오른손·왼손) 표시, 붙임줄·쉼표·임시표·조표·박자표, 4/4 · 3/4 · 2/4 · 6/8, 인쇄/PDF 저장 |
| 수정 | 박자·템포(÷2, ×2)·조성·음표 단위(16분/8분)·양손 경계·약한 음 제거·마디 시작 위치를 바꾸면 **즉시 악보가 다시 그려짐** |
| 재생 | 악보를 피아노 소리로 재생 / 원본 재생 전환, 속도 조절, 재생 마디 강조, 마디·피아노 롤 클릭으로 이동 |
| 내보내기 | **MIDI**(오른손·왼손 2트랙), **MusicXML**(MuseScore 등에서 편집), **피아노 연주 WAV**, **PDF/인쇄** |

## 실행 방법

```bash
npm start            # http://localhost:8080  (의존성 없는 정적 서버)
```

다른 정적 서버를 써도 됩니다(`npx serve .`, `python3 -m http.server` 등). 단, ES 모듈 워커를 쓰므로 `file://` 로 직접 열면 동작하지 않고, 마이크 녹음은 `https://` 또는 `localhost` 에서만 허용됩니다.

**브라우저**: 최신 Chrome / Edge / Firefox / Safari (모듈 워커, Web Audio, WebGL 필요).

## 사용 방법

1. 음악 파일을 끌어다 놓거나 **마이크로 녹음**하거나 **예시 곡**을 눌러 체험합니다. (긴 곡은 처음 5분만 분석하며, 「분석 설정」에서 구간을 바꿀 수 있습니다.)
2. 분석이 끝나면 악보가 나타납니다. 리듬이 어긋나 보이면 **템포 ×2 / ÷2**, 1마디 첫 박이 틀리면 **마디 시작 위치**를 조정하세요.
3. 피아노/원본을 번갈아 들어 보며 확인하고, MIDI·MusicXML·WAV·PDF로 내려받습니다.

## 동작 원리

```
오디오 ─▶ 디코딩·22.05kHz 모노 ─▶ [음 검출 엔진] ─▶ 노트(시작/끝/음높이/세기) + 온셋 곡선
                                      │
        ┌─ AI: Basic Pitch(tfjs, 학습된 다성 음 전사 모델) + 배음 유령음 제거
        └─ 내장: 가변-Q 변환(CQT) → 고정 하모닉 템플릿 NMF → 노트 트래킹 (튜닝 자동 보정)

온셋 곡선 ─▶ 템포 추정(자기상관) ─▶ 동적계획법 비트 트래킹 ─▶ 마디 첫 박 추정
노트 + 비트 격자 ─▶ 16분음표 양자화 ─▶ 양손 분리 ─▶ 마디·음가·붙임줄 ─▶ VexFlow 악보 / MIDI / MusicXML
악보(양자화된 노트) ─▶ WebAudio 가산합성 피아노 ─▶ 재생 / OfflineAudioContext 로 WAV 렌더
```

## 정확도와 한계 (꼭 읽어 주세요)

자동 전사는 완벽하지 않습니다. 결과는 **초안**으로 보고, 필요하면 MusicXML/MIDI를 악보 편집기에서 다듬어 쓰세요.

**이 프로젝트에서 측정한 수치 — 모두 합성 피아노 음원(리버브·잡음·타악기 클릭 포함) 기준이며, 실제 녹음 음원에서의 정확도가 아닙니다:**

| 항목 | 결과 |
| --- | --- |
| 앱 전체(AI 엔진 → 악보 양자화 → MIDI), 박 단위 비교 | 정밀도 0.92 · 재현율 0.87 · F1 0.90 |
| 내장 엔진(음 검출만, 온셋 ±80ms) | F1 0.70 ~ 0.80, 평균 온셋 오차 3ms |
| 템포 추정(70~140 BPM 합성곡 5종) | 모두 3% 이내 |

실제 음악(보컬·드럼·여러 악기가 섞인 곡, 심한 리버브, 녹음 품질이 낮은 파일)에서는 이보다 정확도가 떨어질 수 있습니다. 이 개발 환경에서는 실제 상용 음원으로 검증하지 못했습니다.

알려진 한계:

- **단일 성부 표기**: 한 손(스태프) 안에서 길게 끄는 음 위에 다른 음이 시작하면, 표기 상 앞의 음이 다음 시작점에서 끊깁니다. (MIDI와 피아노 재생은 원래 길이를 그대로 유지합니다.)
- 셋잇단음표·당김음 등 복잡한 리듬은 16분음표 격자로 단순화됩니다. 박자는 4/4·3/4·2/4·6/8만 지원하고, 박자 자동 추정은 하지 않습니다(직접 선택).
- 같은 음의 빠른 반복, 옥타브로 겹친 화음, 매우 높거나 낮은 음은 놓치거나 잘못 잡을 수 있습니다.
- 빠른 곡(약 160 BPM 이상)은 템포가 절반으로 잡힐 수 있습니다. 악보 리듬이 이상하면 **×2 / ÷2** 버튼으로 보정하세요.
- 조성 추정은 음길이 가중 피치클래스 통계 방식이라 화음이 단조로운 곡에서는 틀릴 수 있습니다(직접 선택 가능).
- 음이름 표기는 조표 기준으로 #/♭ 를 고르는 단순 규칙입니다.
- GPU(WebGL)가 없는 환경에서는 AI 엔진이 CPU로 실행되어 매우 느립니다(긴 곡은 「내장 빠른 분석」 권장).
- 이 저장소는 HeadlessChromium(소프트웨어 GL)에서만 검증했습니다. Safari/Firefox, 실제 GPU, 실제 마이크·녹음 장치에서는 테스트하지 못했습니다.

## 프로젝트 구조

```
index.html, css/style.css     화면
js/main.js                    앱 흐름(입력→분석→악보→재생→내보내기)
js/audio/                     디코딩, 녹음, WebAudio 피아노 합성기(+WAV 렌더), 재생 컨트롤러
js/analysis/                  cqt·nmf·transcribe(내장 엔진), ml-engine(AI), rhythm(템포·비트), key(조성),
                              note-filters(배음 유령음 제거), worker·analyzer(스레드 관리·폴백)
js/music/                     score(양자화·손 분리·마디·붙임줄), midi, musicxml
js/render/                    score-view(VexFlow 악보), pianoroll(캔버스)
vendor/                       VexFlow, Basic Pitch 번들 + 모델 (THIRD_PARTY_NOTICES.md 참고)
scripts/serve.mjs             의존성 없는 정적 서버
scripts/build-vendor.mjs      vendor/basic-pitch.bundle.js 재생성 스크립트
tests/                        단위 테스트(node:test), E2E(Playwright)
```

## 테스트

```bash
npm test            # 단위 테스트 (Node 22+, 의존성 없음): 악보 모델·MIDI·MusicXML·CQT·템포·조성·내장 엔진 정확도
npm run test:e2e    # 브라우저 E2E (Playwright + Chromium 필요)
```

E2E는 WAV 업로드 → AI 분석 → 악보 렌더링 → 설정 변경 → 재생 → MIDI/MusicXML/WAV 내려받기(MIDI는 정답과 비교) → 인쇄 화면 → 390px 모바일 폭 → 내장 엔진 → 예시 곡 → 마이크 녹음(가짜 장치) → 잘못된 파일 처리까지 확인합니다. Playwright가 로컬에 없으면 `npm i -D playwright` 후 실행하세요.

## AI 엔진 번들 다시 만들기 (선택)

`vendor/basic-pitch.bundle.js` 는 커밋되어 있으므로 일반적으로는 필요 없습니다.

```bash
npm install --no-save @spotify/basic-pitch@1.0.1 esbuild
node scripts/build-vendor.mjs
```
